## Twenty concrete refinements

1. **One complete daily workflow.** Choose one source→reviewed context→artifact task and keep a reproducible fixture, receipt and restart/export walkthrough.
2. **Explicit format adapters.** Publish a versioned compatibility matrix and round-trip/refusal fixtures for reference, native Context, DIALECTICA and App formats.
3. **Independent evidence verifier.** Implement a separately maintained reader that verifies hashes, source versions, offsets and omissions without importing the producer.
4. **Evidence freshness and withdrawal.** Propagate source corrections, expiry and revoked evidence into dependent capsules/artifacts without erasing prior receipts.
5. **Useful source capture.** Add a bounded source picker with edition, rights, exact spans and page selection; prove reload and recovery on real permitted documents.
6. **Project-specific playable examples.** Let each original adventure open a read-only real example output beside the fictional lesson, using the actual supported format.
7. **Small deployment recipes.** Offer tested fixture-only, local-private and hosted-private recipes, with explicit identity/storage/provider requirements and rollback.
8. **Fresh-clone CI contracts.** Make every advertised command build its prerequisites and run from a clean checkout; keep generated fixtures tracked or reproducibly restored.
9. **Native release artifacts.** Publish pinned native binaries, checksums, licenses/SBOM and platform smoke results for the experimental engines.
10. **Bounded provider jobs.** Use shared durable reservations, one-shot dispatch, cancellation, uncertain-billing reconciliation and end-to-end deadlines before enabling real calls.
11. **Matched human evaluation.** Preregister held-out tasks, blind paired outputs and measure expert quality, analyst time, total tokens, latency and full costs.
12. **Multilingual evidence fidelity.** Test Arabic and mixed-script material with original text, directionality, transliteration uncertainty and explicit offset units.
13. **Conflict-specific distinctions.** Keep statements, events, commitments, interpretations and causal hypotheses as distinct typed objects with source-qualified examples.
14. **Review that survives revision.** Bind human decisions to exact versions and show the dependency changes requiring re-review; never promote model proposals automatically.
15. **Recovery and portability.** Exercise backup/restore, interrupted writes, private exports, tampered inputs and missing dependencies with realistic fixture workspaces.
16. **Clear maintenance rules.** Document one default branch, short-lived feature branches, required checks and exact archive/restore procedures; use repository settings where access allows.
17. **A focused public front door.** Pin the pipeline, Workbench, historical toolkit and methods; keep a current task selector and genuinely useful screenshots.
18. **Credit and license automation.** Maintain upstream/source notices with exact versions, modifications and reuse limits; compare improvements against the correct upstream baseline.
19. **Resolve legacy duplication.** Choose explicit successor/reference roles for the older Compass/website prototypes; repair their real contracts before presenting them as deployable.
20. **Deterministic browser readiness.** Replace timing-sensitive assumptions with observable owner/context/request readiness, retain strict ownership assertions and track flaky checks separately.
