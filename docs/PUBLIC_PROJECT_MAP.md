# Public project map

Reviewed 2026-11-07. 37 public repositories; private projects are excluded.

Start with the [political-data reference examples](https://github.com/sargonxg/TACITUS-Knowledge-Pipeline-open), the [historical research kit](https://github.com/sargonxg/Syria-political-analysis), or the [local source readers](https://github.com/sargonxg/tacitus-workbench). Each repository documents its own setup and data boundaries.

The descriptions below are proposed repository About text. The map does not certify live service availability, benchmark performance, or permission to reuse source. Check the repository license and upstream attribution before reuse. PRAXIS hosted generation is paused.
