## Maintain this map

The source is [data/public-projects.json](../data/public-projects.json). Confirm public visibility and inspect the source before updating it. Run `python scripts/build_project_catalog.py` and the public-catalogue tests. A lifecycle proposal must remain explicitly unexecuted until a separately authorized operation is completed; editing this catalogue never archives or deletes a repository.
